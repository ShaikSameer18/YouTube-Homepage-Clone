# YouTube-Homepage-Clone
A responsive front-end clone of the YouTube homepage built with HTML and CSS. It features a recreated header, sidebar, and video grid layout. Designed using modular CSS (general, header, sidebar, video) to practice modern styling techniques. To run, clone the repo and open youtube.html in your browser.
Here’s a complete `README.md` file you can include in your GitHub repository:

```markdown
# 📺 YouTube Homepage Clone

This is a front-end clone of the YouTube homepage, built using HTML and CSS. The project mimics the look and feel of YouTube’s main page, complete with a header, sidebar, and video content layout.

## ✨ Features

- 🎨 Clean and responsive design
- 🔍 Functional header with search and voice search icons
- 📂 Sidebar with navigation icons and labels
- 🎥 Video grid displaying thumbnails, titles, authors, and stats
- 💡 Modular CSS: separate files for layout, video, header, and sidebar styling

## 🛠️ Tech Stack

- HTML5
- CSS3
